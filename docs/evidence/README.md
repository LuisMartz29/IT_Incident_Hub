# Evidencias que deben guardarse
Guarda capturas y/o exportaciones reales y fechadas de:
1. Azure Boards con el backlog y sus campos.
2. Ramas, commits y seis PR con revisión y validación.
3. Pipeline fallido, diagnóstico, corrección y pipeline exitoso.
4. Agente autohospedado visible y ejecución sobre ese agente.
5. Resultados de `pip-audit` y `npm audit` y decisión tomada.
6. Artefacto publicado y versión/etiqueta.
7. Release con validaciones/aprobación.
8. Aplicación ejecutándose con incidentes de prueba.
Oculta tokens, contraseñas, datos personales y cualquier secreto. Las capturas son apoyo: el historial de las plataformas debe ser verificable.
